# Arcade

Browse directly to [https://nickallan-kerv.github.io/arcade](https://nickallan-kerv.github.io/arcade) to try out the 3D arcade cabinet and play its games.

Walk around with the arrow keys or WASD, or click a cabinet to play. Press `Esc` to return to the arcade.

The cabinet model is credited in [ATTRIBUTION.md](ATTRIBUTION.md).
